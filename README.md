## Description
This project I created a maze game using a tile method to creat the image of the maze. 
the boundaries of the wall wall were created with a list and if statementsthe player 
is controled the arrow keys on the keyboard.Player is repersented as a Jackalope trying
to find its way though the maze to get to it's meal a carrot. once you reach the carrot
it will trigger the winning title screen to congratulate you for finding food!
